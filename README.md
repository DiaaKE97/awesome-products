# Awesome Products — صفحة هبوط السلاسل المخصصة بالاسم

صفحة هبوط ثابتة (HTML + CSS + JavaScript فقط، بدون أي إطار عمل أو خادم) لطلب
سلاسل مطلية بالذهب مكتوب عليها الاسم، عبر واتساب.

تعمل الصفحة بفتح `index.html` مباشرة في المتصفح — لا حاجة لأي تثبيت أو بناء.

```
awesome-products-landing/
├── index.html            الصفحة كاملة
├── css/style.css         التصميم
├── js/script.js          السلوك التفاعلي + الإعدادات القابلة للتعديل
├── download-assets.sh    سكربت لتنزيل الصور المرسلة من العميل
├── README.md             هذا الملف
└── assets/
    ├── images/           الشعار وصورة الهيرو وصور المعرض (فارغ حاليًا)
    └── video/             الفيديو الإعلاني (فارغ حاليًا)
```

## 1) تنزيل الصور المرسلة

روابط العميل كانت صفحات معاينة على Postimages (`postimg.cc/xxxxxxx`)، وهي لا
تصلح كمصدر مباشر للصور. تم حلّها إلى الروابط المباشرة الفعلية
(`i.postimg.cc/...`)، وهي مضمّنة بالفعل في `index.html` كـ **احتياطي تلقائي**:
إذا كان الملف المحلي غير موجود في `assets/images/`، تُحمَّل الصورة تلقائيًا من
الرابط المباشر بدلاً منه — فالصفحة تعمل الآن بدون أي تنزيل، لكن يُفضَّل حفظ
الصور محليًا للسرعة والاستقلالية عن Postimages.

**طريقة سريعة (Mac / Linux / WSL):**

```bash
bash download-assets.sh
```

**طريقة يدوية (أي جهاز):** افتح كل رابط أدناه في المتصفح، ثم "حفظ الصورة
باسم" داخل `assets/images/` بالاسم المطلوب:

لقطات شاشة (screenshots) من واتساب للأعمال وصفحة على Alibaba.com، وليست
صور منتج نظيفة. يُنصح بشدة باستبدالها بصور فعلية للسلاسل قبل النشر:
- صوّر كل نموذج على خلفية بسيطة (قماش كريمي أو رخام فاتح يتماشى مع هوية
  الشعار الدافئة).
- قصّ الصور بنسبة 4:5 تقريبًا لتناسب شبكة المعرض كما هي.
- تأكد أن الصورة القادمة من Alibaba مملوكة لكم أو لديكم إذن استخدامها قبل
  نشرها.
- بعد الاستبدال، حدّث نص `alt` لكل صورة في `index.html` بوصف حقيقي بدلاً من
  الوصف العام الحالي.

## 3) دليل التخصيص

### رقم واتساب
عدّل السطر الأول في `js/script.js`:
```js
const WHATSAPP_NUMBER = "966567025627"; // بصيغة دولية، بدون + أو مسافات
const WHATSAPP_DISPLAY = "+966 56 702 5627"; // الشكل المعروض للزائر
```
كل أزرار الطلب في الصفحة (الهيدر، الهيرو، البطاقات، الشريط السفلي، الزر
العائم، الفوتر) تقرأ هذا الرقم من مكان واحد — لا حاجة لتعديل أي رابط داخل
`index.html`.

### العملة
```js
const CURRENCY_LABEL = "[العملة]"; // مثال: "ر.س"
```
تظهر بجانب كل سعر في بطاقات الأسعار وفي رسالة واتساب.

### الأسعار والخيارات الثلاثة
داخل `index.html`، ابحث عن `id="pricing"`. كل بطاقة `<article class="plan" ...>`
تحتوي على:
```html
<span class="plan__name ph" data-plan-name>[اسم الخيار 1]</span>
<span class="plan__desc ph">[وصف مختصر للخيار]</span>
<span class="plan__price"><b class="ph" data-plan-price>[السعر]</b> ...
```
عدّل النصوص بين الوسوم مباشرة. لا تحذف `data-plan-name` أو `data-plan-price`
— هذه الخصائص هي ما يقرأه الكود لبناء رسالة واتساب تلقائيًا.

### نص رسالة واتساب
في `js/script.js`:
```js
const MESSAGE_GREETING = "السلام عليكم  أبي أطلب سلسلة مخصّصة بالاسم 🤍"; // لا تغيّره
const MESSAGE_NO_OPTION = "لم أحدده بعد";
const MESSAGE_NAME_LATER = "سأرسله في المحادثة";
const MESSAGE_CLOSING = "أرغب في معرفة تفاصيل الطلب والدفع عند الاستلام.";
```
ولبناء الرسالة نفسها، عدّل داخل دالة `buildMessage(...)` في نفس الملف.

### صورة الهيرو
```html
<img src="assets/images/hero-product.jpg" ... alt="سلسلة مطلية بالذهب مكتوب عليها اسم">
```
استبدل الملف في `assets/images/hero-product.jpg` بأي مقاس — الإطار مصمم
ليتكيف مع أي نسبة أبعاد قريبة من 3:4.

### صور المعرض
عدّل الملفات في `assets/images/gallery-01.jpg` إلى `gallery-06.jpg`. لتغيير
الجزء الظاهر من صورة طويلة داخل المربع، عدّل `style="--pos: 50% 45%"` على
وسم `<img>` (النسبة المئوية الثانية تتحكم بالموضع الرأسي).

### الفيديو الإعلاني
راجع القسم 2 أعلاه.

### الأسئلة الشائعة
كل سؤال داخل `id="faq"` هو كتلة `.faq__item` مستقلة — عدّل نص السؤال داخل
`<button class="faq__q">` والإجابة داخل `<div class="faq__a">`. النصوص
الموسومة بـ `<span class="ph">[...]</span>` هي عناصر تنتظر تأكيد الشركة.

### سياسة الإرجاع
داخل `id="returns"`، كل صف `.policy__row` يمثل بندًا. استبدل `[تُحدد
بواسطة الشركة]` بالسياسة الفعلية عند اعتمادها.

### ألوان العلامة التجارية
كل الألوان معرّفة كمتغيرات CSS في أعلى `css/style.css`:
```css
:root {
  --primary-gold: #D9912B;
  --gold-light: #F4D18A;
  --gold-deep: #B98528;
  --cream: #FFFDF8;
  ...
}
```
تغيير أي قيمة هنا ينعكس على الصفحة كاملة. لا تغيّر `--whatsapp-green` أو
`--whatsapp-dark` — هذان لونا واتساب الرسميان.

### الزر العائم لواتساب (ديسكتوب)
عنصر `.wa-float` في `index.html` (بحث عن `wa-float`)، وتنسيقه في
`css/style.css` تحت "Desktop floating WhatsApp button". يظهر فقط على الشاشات
1024px فأكبر لتجنب التداخل مع الشريط السفلي على الجوال.

### الشريط السفلي الثابت (موبايل)
عنصر `.order-bar` في نهاية `index.html`. يعرض اسم/سعر الخيار المختار
تلقائيًا بمجرد اختيار العميل خيارًا من قسم الأسعار. يظهر فقط أسفل 768px.

## 4) قائمة الاختبار قبل النشر

- [ ] تفتح الصفحة بشكل صحيح من `index.html` مباشرة (بدون خادم).
- [ ] الاتجاه RTL صحيح في كل الصفحة، والنصوص والأزرار محاذاة يمينًا/يسارًا
      بشكل طبيعي.
- [ ] التصميم يعمل على الجوال والتابلت والديسكتوب (320 حتى 1440px فأكثر).
- [ ] قائمة الجوال (☰) تفتح وتُغلق، وتُغلق تلقائيًا بعد اختيار رابط.
- [ ] كل روابط التنقل الداخلي (`#features`, `#gallery`, ...) تعمل بتمرير
      سلس.
- [ ] كل أزرار واتساب تستخدم نفس الرقم من `WHATSAPP_NUMBER`.
- [ ] رسالة واتساب تبدأ حرفيًا بـ: «السلام عليكم  أبي أطلب سلسلة مخصّصة
      بالاسم 🤍».
- [ ] الرسالة مُرمَّزة بشكل صحيح داخل الرابط (URL encoding) — لا مسافات
      خام في الرابط.
- [ ] الفيديو العمودي يحافظ على نسبة 9:16 دون تشويه (أو يظهر بديل أنيق إن
      لم يُرفع الملف بعد).
- [ ] قائمة الأسئلة الشائعة تفتح/تُغلق بشكل صحيح (سؤال واحد مفتوح كحد
      أقصى).
- [ ] معرض الصور يعمل، والتكبير (lightbox) يفتح ويتنقل بالأسهم ويُغلق
      بـ Esc.
- [ ] أيقونة واتساب المستخدمة هي الأيقونة الرسمية الحقيقية (Font Awesome
      Brands)، بلونها الأخضر الرسمي دون تعديل.
- [ ] لا توجد أيقونات SVG مرسومة يدويًا في الصفحة.
- [ ] الزر العائم لواتساب يعمل على الديسكتوب.
- [ ] الشريط السفلي الثابت يعمل على الجوال ولا يتداخل مع محتوى الصفحة أو
      الفوتر.
- [ ] هناك تباعد كافٍ من الأسفل يراعي مناطق الأمان (safe-area) في الأجهزة
      ذات الحواف المستديرة/الشريط السفلي.
- [ ] لا يوجد تمرير أفقي (horizontal scroll) في أي مقاس شاشة.
- [ ] لا توجد أخطاء غير ضرورية في console المتصفح.
- [ ] تفضيل تقليل الحركة (`prefers-reduced-motion`) يُحترم — الخلفية
      المتحركة تتوقف والحركات التمهيدية تُعطَّل.
- [ ] الصفحة قابلة للاستخدام حتى عند عرض 320px.

تم اختبار جميع البنود أعلاه آليًا (باستثناء المراجعة اليدوية للصور
الحقيقية بعد استبدالها، والتي تبقى مسؤولية من ينشر الصور).

## 5) ملاحظات مهمة

- لا تُجمع أو تُخزَّن أي بيانات من الزائر على الخادم — الاسم المُدخَل
  اختياري ويُستخدم فقط داخل رابط واتساب المُنشأ في المتصفح.
- لا يوجد أي نظام دفع أو تأكيد طلب وهمي داخل الصفحة — إتمام الطلب الفعلي
  يحدث بالكامل داخل محادثة واتساب.
- واتساب علامة تجارية مملوكة لأصحابها؛ لا توجد أي شراكة أو رعاية أو تأييد
  من واتساب لهذا الموقع (تنويه مطابق موجود في تذييل الصفحة).
- الأسعار وسياسة الإرجاع ومدة التوصيل والضمان كلها عناصر نائبة (placeholders)
  إلى حين اعتماد الشركة للتفاصيل الرسمية — لا تنشر الصفحة دون استبدالها.
